# Karthik S — Portfolio

Static portfolio site (HTML, CSS, JavaScript). No build step.

## Files
- `index.html` — page structure and content
- `style.css` — styles (light/dark aware)
- `script.js` — project demos, to-do storage, contact form

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Push these files to a repository.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Site appears at `https://<username>.github.io/<repo>/`.

## To customize
- Replace the `github.com/username/...` and LinkedIn placeholder links in `index.html`.
- The contact form opens the visitor's email app. For real form submissions, use a service such as Formspree.
