# Karthik S: Portfolio

Personal portfolio built with HTML, CSS, JavaScript and a small Python script.

- `index.html`: page structure
- `assets/`: styles, scripts and `data.json`
- `backend/build_data.py`: edit your skills and interests here, then run `python backend/build_data.py`

Preview locally: `python -m http.server` and open http://localhost:8000
